# Interactive Photo Gallery - Interactivity with JavaScript

Course: Interactivity with JavaScript (University of Michigan / Coursera)  
Author: kiennguyen123-code

## Overview
This interactive photo gallery demonstrates DOM manipulation using JavaScript:
- `upDate(previewPic)`: Handles the `mouseover` event by updating the `#image` div's background image to the hovered thumbnail's `src` and setting the text to its `alt` description.
- `unDo()`: Handles the `mouseout` event by resetting the background image to `url('')` and restoring the original instruction message.
- Uses `console.log()` statements to log event firing and element details as requested by the rubric.
